# Control de Gastos Mensuales (PWA)

Aplicación web progresiva (PWA) 100% privada y offline-first para el control y gestión de presupuestos y gastos mensuales.

## Características
- **100% Privada y Local:** Los datos residen exclusivamente en el dispositivo mediante IndexedDB.
- **Offline-First:** Funciona sin conexión a internet y se puede instalar como aplicación nativa.
- **Gestión Rápida:** Registro de gastos por categorías, métodos de pago y visualización de saldo mensual.

## Stack Tecnológico
- **Frontend:** React + Vite
- **Estilos:** Tailwind CSS
- **Base de Datos Local:** Dexie.js (IndexedDB)
- **PWA Engine:** vite-plugin-pwa (Workbox)

## Instalación y Desarrollo 
bash
npm install
npm run dev
